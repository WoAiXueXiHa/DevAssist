# DevAssist 知识库原始资料

本目录存放系统的**知识库原始资料**——即 RAG（检索增强问答）所检索的源文档。这些资料既被后端用于切片、向量化、检索，也可供运营人员维护、用户直接查阅。

## 资料清单（`knowledge/`）

| 文件前缀 | 分类 | 主要内容 |
| --- | --- | --- |
| `01-*.md` | 接入 | 注册实名、创建应用、获取 API Key、调用流程、接入检查清单 |
| `04-*.md` | 回调 | 回调机制、重试策略、验签、收不到回调的排查 |
| `06-*.md` | 计费 | 套餐档位、计费方式、账单上涨原因、用量查询 |
| `07-*.md` | 数据质量 | 数据来源与更新、返回为空/不一致的处理 |
| `08-*.md` | FAQ | 高频问题速查 |

当前目录包含 5 份资料，尚缺 `02` 鉴权签名、`03` 错误码与 `05` 限流重试独立手册。FAQ 中的简要规则不能替代完整平台规范。

## 格式与维护说明

- 所有资料均为 **Markdown（`.md`）** 格式，纯文本、可版本管理、便于运营直接编辑。
- 文件名前缀数字用于排序；前缀映射到分类（见上表），ingest 时自动识别。
- 切片器支持将 `AUTH_KEY_EXPIRED（HTTP 401）` 形式的章节标题解析为 `error_code` 标量字段；需要对应知识资料才能获得实际检索覆盖。
- **更新资料后需重新索引**：在项目根目录执行 `make ingest`（付费 Embedding），随后重启 AI 服务以刷新进程内 BM25 缓存。

## 检索链路

```
data/knowledge/*.md
  → 切片(按章节, 400-600字)
  → DashScope text-embedding-v3 向量化
  → 写入 Milvus（含 doc_title/section/category/error_code 标量）
  → 在线：向量检索 + BM25 混合 → RRF → gte-rerank 精排 → 上下文压缩 → 带引用生成
```
